# 알림 센터 2차 기획 회의

- 일시: 2026-11-04(수) 14:00~15:20
- 장소: 본관 7층 회의실 A
- 참석자: 정하늘, 오지현, 한도윤, 이서연(플랫폼), 배수아, 차민호, 유다인
- 작성자: 한도윤

## 1. 이메일 다이제스트 발송 시간
- 오지현 책임: 사내 설문 결과 "출근 전에 확인하고 싶다"는 응답이 62%. 8시가 낫다.
- 정하늘 팀장: 그럼 8시로 바꾸자.
- 유다인 선임: 템플릿 마감이 내일인데, 발송 시간 문구가 바뀌니까 금요일까지로 미뤄 달라고 요청. → OK.

## 2. 알림 설정 화면
- 사용자 피드백: 알림 종류별 on/off만으로는 부족하고 "업무 시간 외 알림 끄기"가 필요함.
- 한도윤 선임: 설정 화면 기획서에 업무 시간 외 끄기를 추가해서 내일까지 다시 공유하겠음.
- 차민호 선임: 기획서 나오면 설정 화면 UI 시안은 이번 주 안에 드리겠음.
- 이서연 선임(플랫폼): 업무 시간 설정을 저장하는 API가 필요함. 목요일 오전까지 API 스펙 공유하겠음.
- 배수아 선임: 설정 화면 프론트는 다음 달 첫째 주쯤 가능할 것 같음.
- 정하늘 팀장: 그건 너무 늦음. QA 시작 전까지는 들어가야 함. → 배수아 선임이 QA 시작 전까지 완료하기로.

## 3. 오픈 공지
- 오지현 책임: 오픈 공지에 알림 센터 소개와 설정 방법을 넣겠음. 오픈 2주 전까지 초안 공유.

## 4. 앱 푸시
- 앱 팀에서 일정 문의가 왔으나 2차 범위 유지.

## 결정 사항
- 이메일 다이제스트 발송 시간 **오전 9시 → 오전 8시**로 변경.
- 알림 설정에 **업무 시간 외 알림 끄기** 기능 추가.
- 앱 푸시는 2차 유지.
