# 모의 데이터 설명

모든 데이터는 가상의 회사 **에이엑스랩**의 **스마트오피스 포털 v2** 프로젝트(오픈 2026-12-14)를 기준으로 만든 것입니다. 인물, 이메일, 전화번호, 주민번호는 모두 가짜입니다.

> 이 문서에는 샘플별 **정답과 테스트 의도**가 들어 있습니다. Agent가 이 파일을 읽으면 평가가 무의미해지므로 RAG 인덱싱 대상에서 빼야 합니다.

## 파일 구성

| 경로 | 용도 | 사용하는 곳 |
|---|---|---|
| `org.json` | 직원 30명, 7개 팀 | `directory-server` |
| `seed/tasks.json` | 과거 회의에서 나온 업무 34건 (기준일 2026-11-01) | `task-server` 초기 데이터 |
| `seed/calendar.json` | 회의, 휴가, 휴직, 공휴일, 주요 일정 | `calendar-server` 초기 데이터, 날짜 계산 |
| `past_meetings/` | 과거 회의록 15건 (2026-08-31 ~ 10-26) | RAG 인덱싱 |
| `samples/` | Agent에 넣을 새 회의록 5건 (2026-11-02 ~ 11-10) | 데모, 평가 |

## 조직도에 넣은 함정

| 동명이인 | **이서연** 2명: E007 플랫폼개발팀 선임(알림 API) / E013 프론트엔드팀 책임(대시보드) |
| 같은 호칭 | "박 선임": E008 박지훈(플랫폼) / E019 박소율(QA) |
| 휴직자 | E011 임성민: 11월 한 달 휴직(`status: on_leave`). 할 일을 배정하면 안 됨 |
